# LightFC Deploy

本仓库用于集中存放 LightFC 的相关部署项目。每个项目均位于独立的子文件夹中。

---

## TrackingApp

一款在 Android 设备上离线运行的轻量级目标跟踪应用，使用 ncnn 部署 LightFC 模型。

主要功能：

- 支持静态图片目标跟踪
- 支持本地视频目标跟踪
- 支持手机摄像头实时目标跟踪
- 显示跟踪置信度、推理耗时和 FPS
- 支持 LightFC 模型的导入、校验与切换

apk文件在“./TrackingApp/TrackingApp.apk”
